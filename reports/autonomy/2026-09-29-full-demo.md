# 综合自主巡航升级记录（2026-09-29～30）

基于 `feat/slam`，保留工作区原有的 0.20 m/s 速度上限调整。没有修改静态场景、碰撞网格、车辆 URDF、DiffDrive、WheelSlip 或摩擦参数，没有引入 Nav2。

## 路线与任务

默认 `bash launch_autonomy.sh` 选择 `full_demo`；`mission:=perimeter` 保留外围模式。

综合任务约 21.45 m、19 个有序开放段：AB 起点 → B 弯 → 右外围 → 向西进入十字路口（signal_1）→ 转中央北向道路 → P5 环岛 225° → 左停车场入口 → 场内 S 形穿越 → 右入口离场 → 右上坡/C 弯 → 后方高架 → D 弯/左下坡 → signal_6 → 向东进入十字路口（signal_2）→ 中央南向道路 → AB 起点。

依据 `config/scene/*.json`、生成器和现有 `model.sdf`/碰撞 OBJ 核验路线，未改变道路或道闸。P5 中心 `(1.65,3.98)`，环岛轨迹使用半轴 `(0.47,0.41)` 的椭圆，避让北侧灯杆；两个停车场入口以车身包络核验，而非仅检查中心线。静态包络检查为 1 cm 采样、车身外扩 5 mm。

`mission.py` 加载 JSON 段序列，约束投影只在当前段和历史进度窗口内搜索。前视目标可以延伸至下一段，完成条件同时检查进度、端点距离和车头方向。显式恢复自动模式时按当前段、下一段、上一段顺序检查距离/方向，不全图重选任务阶段。

## 感知、灯色和安全

- 图像中的当前方向灯头 ROI 是唯一灯色来源；signal_1 为西向，signal_6 为南向，signal_2 为东向。外围模式仍使用 signal_7 和 signal_6。
- 绿灯需要 3 个不同新图像帧；红/黄/未知均等待。综合演示额外要求先停车观察到红/黄灯，再等下一轮绿灯（JSON 的 `require_new_green`）；到达时已有绿灯也等待新周期，控制器不读取信号周期时钟或灯色真值。授权窗口限定在最后一次图像红/黄观测后的 2 秒；短暂传感器中断仍停车并清空帧确认，窗口内恢复可重新累计三帧，窗口外必须再等红/绿转换。车头过线后锁存 CROSSING，直到驶出当前路口。斑马线/箭头必须与地图停车线的预测距离相符，才参与视觉停止线修正。
- 普通道路要求车道检测；路口、环岛、停车场、坡道取消双侧车道线硬要求，保留姿态、路径偏离和雷达保护。
- 相机、雷达、IMU、odom 新鲜度为 0.5 s；定位修正允许 1.5 s 内短时断续，0.5 s 后限速 0.09 m/s，超过 1.5 s 停车。定位仍以新鲜 odom/IMU 传播，不允许持续无定位盲开。
- 雷达制动距离包含实际轮速；停车后仍检查计划曲率的车身扫掠，避免在“曲线有障碍/直线无障碍”之间反复起停。
- 人工输入锁存 MANUAL；显式 `/autonomy/enable` 才恢复。非法 clearance/严重偏离/无进展锁存 FAULT_STOP，时钟回退必须重启。命令仲裁和下游 guard 的 0.4 s timeout 保留。

停车场 `mapping.py` 使用 scan-to-submap 平移匹配与已有静态地图全局约束，在线更新占据格；发布 `/autonomy/parking_map`，保存 PGM/YAML/NPZ。它是局部、有全局锚定的雷达 SLAM，不提供完整回环优化。新增障碍物会被建图和雷达安全停车处理，尚不提供动态绕行规划或自动泊车。建图与局部匹配排除车身范围内的自反射，防止在空停车场留下沿轨迹排列的假占据点；车身外近距离回波仍保留。

## 坡道问题定位

原实现基线实跑：`reports/autonomy/baseline/`。在 C 弯，小车真值仍在道路中心（停车时约 `(2.8910,5.0479)`），估计位置却被 ICP 拉到 `(2.7103,5.0316)`，最终触发 `outside lane corridor`。实际最大道路中心偏差仅约 1.10 cm；估计横向/纵向累计偏差约 18 cm。此前增大速度并不能消除这个误定位问题。首次故障记录为仿真 38.25 s：pitch 约 −0.0064 rad，定位更新年龄 0.139 s，雷达未报告制动范围内障碍；故障前仍发出 0.15 m/s，随后控制器主动输出零。该次复现并非轮地打滑、lane lost、数据超时或无进展 watchdog；未为此修改物理模型。

修复：连续跟踪时为 ICP 增加轮式里程计/IMU 预测先验，拒绝大于 3.5 cm 的单次创新及明显偏离地图通行走廊的修正；不将位置吸附到路线，也不读取车辆真值。坡道改为明确任务段，使用独立速度与车道策略，保留障碍物制动和无进展 watchdog。
