## 4. 已实现与已修复

### 4.1 启动与显示

`launch_car.sh` 增加 `--autonomy` 入口；自主入口、整圈验收、动力学探针、故障注入脚本均沿用它加载场景。

`simulation.launch.py` 增加 `sensor_software_rendering`，自主模式默认开启：仅服务器作用域设置 `LIBGL_ALWAYS_SOFTWARE=1`，服务器使用 Ogre2 渲染相机和 GPU 雷达；GUI 独立进程使用 X11/Ogre1，继承原硬件环境。run11 实际进程环境已核对，用户确认显示改善。

VMware 上纯硬件传感器渲染曾输出纯色图像或无效扫描；此服务器软件渲染配置仍需保留。不要全局设置 `LIBGL_ALWAYS_SOFTWARE=1`。软件传感器请用有效 DISPLAY；`headless:=true` 关闭窗口，不能与 EGL 的 `headless_rendering:=true` 混淆。

### 4.2 传感器与控制闭环

- RGB 640×480 / 20 Hz、CameraInfo、360° 720 束雷达 / 10 Hz、IMU / 50 Hz，以及里程计桥接。
- 已知道路路线跟踪、图像道路识别、图像灯色识别、停车线图像测距。
- 里程计前进增量 + IMU 姿态 + 激光静态地标匹配修正 XY；发布 map → odom。
- 驾驶状态机、绿灯连续 3 个不同图像帧确认、传感器缺失/过期停车、障碍停车、路线偏离/丢道/无进展保护。
- 手动/自动命令仲裁，最终经过 command_guard；人工停车锁定手动，需显式重新启用自动。
- 时间回退锁存故障；关键进程退出触发 launch 清理。

### 4.3 轮胎/坡道动力学根因已经修复

旧碰撞名 `rolling_tyre` 使 sdformat 转换丢掉轮子 surface/friction 参数，此前调整 fdir1 并未真实进入物理模型。生成器改用默认碰撞名后，四轮摩擦参数在实际 URDF → SDF 中保留。

圆柱碰撞绕 X 转 -π/2；碰撞坐标的 +Z 对应轮链接 +Y 轮轴，最终 `fdir1=0 0 1`，WheelSlip lateral=.5、longitudinal=0。**不要恢复旧指南里的 `0 1 0` 推断。**

同一起点 `v=.06, w=.15` 的 6 秒受控对照：修复前实测偏航约 .009 rad/s；修复后约 .143 rad/s，线速度约 .0578 m/s。之后真实仿真通过坡道与四个弯。

证据：`reports/autonomy/probe_surface_fixed/` 及同目录其他 `probe_*`；转换回归在 `src/dongfeng_bringup/test/test_sensors.py`。

### 4.4 A 弯下坡定位发散已经修复并实跑验证

run10 在最后 A 弯处激光局部 ICP 错配重复表面，真实 X≈.606，估计 X≈.414，触发故障。真实扫描回放能复现从约 -2.7 cm 的 Y 偏差逐渐发散成约 -24 cm 的 X 偏差。

`localization.py` 增加 ±6 cm 粗搜索与 Cauchy 权重；真实扫描回归通过，run11 随后成功经过 A 弯回到起点。夹具：`src/dongfeng_autonomy/test/fixtures/a_bend_scan.npz`；采样：`reports/autonomy/probe_localization_a/`。

### 4.5 安全与独立验收改进

- 明确 `line_s` 实体停车线、`stop_s` 车体中心停车目标。前伸 .1032 m、余量 .035 m；只有车头真正越线才提交 CROSSING。
- 手动禁用不累计绿帧、不推进任务。最新补充修复：长距离倒车后，物理位置独立投影并解除旧通行状态；超出进度窗口后重新启用自动会停车要求重启任务。`LongManualReverseTest` 已通过，尚未独立审查复核和实际仿真倒车验证。
- 障碍检测覆盖整个矩形车体的前方运动区域和弯道车尾侧摆；对必需角区检查激光有效性，NaN 盲区不当作畅通，+inf 仍是有效无回波。
- 拒绝无效/不可用 IMU 四元数、非有限角速度和重复旧帧，拒收时不刷新数据新鲜度。
- 验收器核验真实起点、顺序 B/C/D/A、连续性、完整进度、返回距离、朝向和至少 2 秒停稳。车体边界按约 2 cm 采样，避免只看四角漏掉弯道内侧越界。
- 状态 JSON 使用严格格式，非有限值转 null，包含 `sim_time`、`frame`、`stop_distance`。
